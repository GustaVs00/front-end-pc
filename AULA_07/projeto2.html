Este é um exemplo de menu de navegação responsivo. Redimensione a janela do navegador ou use o DevTools (F12 → ícone de celular) para ver o menu se transformar de horizontal para vertical.

Seção de Conteúdo

Observe como o header fica fixo no topo enquanto você rola a página. Isso é feito com position: fixed no CSS.

Outra Seção

O efeito de hover nos links do menu usa transition para suavizar a mudança de cor. Sem transition, a mudança seria instantânea e brusca.
